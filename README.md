## Запуск проектов

- **ЧистоДома:** файлы приложения находятся в [`Prac3`](Prac3); пример переменных окружения — [`Prac3/.env.example`](Prac3/.env.example). Для PostgreSQL предусмотрен [`compose.yaml`](Prac3/compose.yaml).
- **CORS:** следуйте [инструкции проекта](PracCORS/cors-practice/README.md). Она описывает запуск режимов «до» и «после» настройки политики.
- **Аутентификация:** команды запуска, тестовый пользователь и описание способов входа приведены в [README проекта](PracAuth/README.md).

### Безопасность «ЧистоДома»

Сервер отправляет `Content-Security-Policy`, `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy` и `Cross-Origin-Opener-Policy`. Сессионная cookie использует `HttpOnly` и `SameSite=Lax`; `Secure` добавляется при работе через HTTPS.

Локальные пароли хранятся в `.env`, который не загружается в репозиторий. Для настройки используется [пример файла](Prac3/.env.example).
