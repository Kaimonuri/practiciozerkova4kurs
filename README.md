## Безопасность проекта «ЧистоДома»

В проекте настроены заголовки `Content-Security-Policy`, `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy` и `Cross-Origin-Opener-Policy`. Сессионная cookie использует параметры `HttpOnly` и `SameSite=Lax`; параметр `Secure` включается при работе через HTTPS.

Локальный файл `.env` с паролями не загружается в репозиторий. Для настройки используется безопасный пример `Prac3/.env.example`.
